# msa4-css

CSS의 기본 문법부터 Flexbox·Grid를 이용한 화면 배치까지 학습하는 예제 모음입니다. 주제별 HTML·CSS를 비교하고, 복습 문제와 페이지 구성 실습으로 이어갈 수 있습니다.

## 처음 시작하기

1. 저장소 전체를 내려받아 폴더 구조를 유지합니다.
2. [스타일시트 적용 예제](edu/01_styleSheet.html)를 웹 브라우저에서 엽니다.
3. 코드 편집기에서 HTML과 연결된 [01.css](edu/01.css)를 함께 확인합니다.
4. CSS의 스타일 값을 바꾼 뒤 저장하고 브라우저를 새로고침합니다.

별도의 패키지 설치나 빌드 과정은 없습니다. HTML만 따로 옮기면 상대 경로로 연결한 CSS·이미지가 표시되지 않을 수 있습니다.
